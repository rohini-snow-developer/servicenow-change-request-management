# ServiceNow Change Request Management System

## Project Overview

This project demonstrates a Change Request Management System developed using ServiceNow.

The system helps organizations create, assess, approve, schedule, implement, and close change requests in a controlled manner.

## Technologies Used

- ServiceNow
- JavaScript
- ITSM
- Change Management
- Flow Designer
- Client Scripts
- Business Rules
- UI Policies
- GlideRecord
- Notifications

## Key Features

- Create Change Requests
- Change Type Selection
- Risk and Impact Assessment
- Change Approval Process
- Assignment Group Management
- Implementation Plan
- Change Scheduling
- Automated Approval using Flow Designer
- Business Rules for server-side automation
- Client Scripts for form validation
- UI Policies for dynamic form behavior
- Email Notifications
- Change Lifecycle Management

## Change Lifecycle

New → Assess → Authorize → Scheduled → Implement → Review → Closed

## ServiceNow Components

### Client Script
Used for client-side form validation and dynamic field behavior.

### Business Rule
Used for server-side validation and automation.

### UI Policy
Used to make fields mandatory, visible, or read-only based on conditions.

### Flow Designer
Used to automate approval and notification processes.

### GlideRecord
Used to query and update ServiceNow records.

The objective of this project is to demonstrate practical knowledge of ServiceNow Change Management and ServiceNow development concepts.
