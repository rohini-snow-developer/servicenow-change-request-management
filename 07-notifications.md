# Email Notifications

## Notification 1 - Change Submitted

### Trigger
When a Change Request is created.

### Recipients
- Requested By
- Assignment Group

### Message
Your Change Request has been submitted successfully.

---

## Notification 2 - Change Approved

### Trigger
When the Change Request is approved.

### Recipients
- Requested By
- Assigned To

### Message
Your Change Request has been approved and is ready for implementation.

---

## Notification 3 - Change Rejected

### Trigger
When the Change Request is rejected.

### Recipients
- Requested By

### Message
Your Change Request has been rejected. Please review the approval comments.

---

## Notification 4 - Change Closed

### Trigger
When the Change Request is closed.

### Recipients
- Requested By
- Assignment Group

### Message
The Change Request has been successfully completed and closed.
